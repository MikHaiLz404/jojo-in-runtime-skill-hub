# UI/UX Pro Max

Comprehensive UI/UX design skill for web and React/Next.js applications.

## Capabilities

- Design system creation
- Component styling with Tailwind CSS
- Responsive design
- Accessibility (WCAG 2.1)
- Color palette selection
- Typography pairing
- Layout patterns
- 9 framework stacks: React, Next.js, Vue, Svelte, SwiftUI, Flutter, Tailwind, shadcn/ui
- 50 design styles
- 21 color palettes

## Supported Frameworks

| Stack | Technologies |
|-------|--------------|
| React | React 18+, Hooks, Context |
| Next.js | App Router, Server Components |
| Vue | Vue 3, Composition API |
| Svelte | Svelte 5, SvelteKit |
| SwiftUI | iOS development |
| Flutter | Cross-platform mobile |
| Tailwind | CSS utility framework |
| shadcn/ui | Component library |

## Usage

```
Use @ui-ux-pro-max when designing UI components
Use @ui-ux-pro-max for accessibility review
Use @ui-ux-pro-max for design system implementation
Use @ui-ux-pro-max for color palette selection
Use @ui-ux-pro-max for typography pairing
```
